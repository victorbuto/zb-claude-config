# Формат TXT для импорта в Miro Mind Map

Miro строит майндмап из обычного текстового файла, где иерархия задаётся **отступом в табах** (один таб = один уровень вложенности).

## Как пользователь импортирует
1. В Miro: создать фрейм Mind Map → меню (•••) → **Import** → выбрать `.txt`.
2. Или перетащить `.txt` на холст с выбранным Mind Map.

## Правила формата (строго соблюдать при генерации)
- **Только табы** для отступа (НЕ пробелы) — иначе уровни не распознаются.
- Один корневой узел в самом верху без отступа = формулировка задачи (Точка Б / задача).
- Каждый следующий уровень = +1 таб.
- Один пункт = одна строка. Без маркеров `-`, `*`, без нумерации, без markdown.
- Узлы держать короткими (2–6 слов) — это узлы майндмапа, не предложения.
- Пустые строки не использовать.

## Пример (символ → = таб)

```
Снять квартиру до 1 сентября
→Аудитория
→→Собственники напрямую
→→Риелторы
→Каналы поиска
→→Авито / Циан
→→Телеграм-чаты
→→Сарафан
→Оффер для хозяина
→→Платёжеспособность
→→Длительный срок
→Воронка просмотров
→→Отбор объявлений
→→Звонки
→→Просмотры
```

При записи в файл заменить `→` на реальный символ табуляции.
