# Person Profile — создание профиля из транскрипта встречи

## Входные данные

Пользователь предоставляет:
1. **Транскрипт встречи** — файл или ссылка (обязательно)
2. **Ссылка на профиль человека** — Telegram, LinkedIn и т.д. (опционально)

## Процесс

### 0. Конвертация .whisper → txt (если нужно)

Если файл имеет расширение `.whisper`, конвертируй его через скрипт перед чтением:

```bash
python3 "/Users/fixed/Documents/ZB CLOUD 3600/.claude/skills/person-profile/scripts/convert_whisper.py" "<путь к файлу>.whisper"
```

Скрипт создаст `.txt` файл рядом с `.whisper`. После этого читай `.txt` файл частями через `offset` и `limit` (файл может быть большим).

### 1. Прочитать транскрипт
- Определить участников встречи
- Пользователь = **Виктор Буто**, руководитель отдела стратегии в ONY и Signal. Его профиль не создавать.
- Если на встрече несколько собеседников рассказывали о себе — создать отдельный файл для каждого (по одному на человека)

### 2. Извлечь информацию о каждом собеседнике
Из транскрипта достать:
- Имя и фамилия
- Контакт (Telegram, email — если упоминается)
- Должность и формат работы (штат/фриланс)
- Компания (текущая и прошлые)
- Город / страна
- Область компетенций и конкретные навыки
- Индустрии, в которых работал
- Чем конкретно может помочь
- Интересы, хобби

### 3. Сформировать summary встречи
- Контекст: как познакомились, зачем встречались
- Ключевые темы и инсайты
- Точки пересечения интересов
- Договорённости и следующие шаги

### 4. Создать файл

**Путь:** `/Users/fixed/Documents/ZB CLOUD 3600/CLOUD ZB (3600)/People/`

**Имя файла:** `Имя Фамилия — Должность или суть деятельности.md`
- Название на русском, если слова употребимы в русском
- На английском — только если нет устоявшегося русского аналога

**Формат:** см. [references/template.md](references/template.md)

### 5. Ключевые правила
- Если о человеке слишком мало контекста (мимолётное упоминание, без должности, без сути деятельности, без договорённостей) — профиль не создавать. Сообщить пользователю, что недостаточно данных.
- Писать ёмко и конкретно, без воды
- Summary встречи — 3–5 предложений, факты и договорённости
- Описание человека в шапке — 2–3 предложения, суть
- Если информация не упоминается в транскрипте — не выдумывать, ставить «(уточнить)»
- Дата встречи = текущая дата, если не указано иное
- Секции без информации — не включать (например, если хобби не обсуждались — пропустить)
