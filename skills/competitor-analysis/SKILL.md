# Competitor Analysis

Глубокий разбор одного конкурента по открытым данным: рынок, стратегия, финансы, ЦА, продукт. Четыре параллельных агента собирают сырьё → один саммари-отчёт.

Методология — на основе статьи Виктора Буто «150 идей для анализа конкурентов» (vc.ru, 2022). Покрываемые блоки: 1 (рыночное поле), 2 (стратегия), 3 (финансы и метрики), 4 (ЦА), 5 (линейка продуктов).

## Инпут

Спросить у пользователя (если не указано):
1. **URL сайта конкурента** (обязательно)
2. **Краткий контекст**: что за компания, на каком рынке (опционально, если по URL не очевидно)
3. **Бизнес-задача** анализа — для чего смотрим (опционально, влияет на акценты в синтезе)

Если в `Researches/` уже есть материалы по этой компании (профиль из company-profile-search или brand-analysis) — подхватить базовые факты, не дублировать.

## Шаг 1. Создать папку проекта

Slug = латиница, нижний регистр, дефисы. Например: `notion`, `miro`, `tinkoff-business`.

```
/Users/fixed/Documents/ZB CLOUD 3600/CLOUD ZB (3600)/Researches/[slug]-competitor/
```

Внутри — 5 файлов: 4 от агентов + 1 итоговый синтез.

## Шаг 2. Запустить 4 параллельных агента

**ВАЖНО:** все четыре вызова `Agent` — в одном сообщении (один блок tool-calls), `subagent_type="general-purpose"`. Каждый агент сам пишет результат в свой файл через `Write` и возвращает короткое резюме.

Полные промпты агентов: [references/agent-prompts.md](references/agent-prompts.md). Общие требования для всех:
- Использовать `WebSearch` и `WebFetch` для сбора данных
- Цитаты-доказательства / конкретные факты под каждым утверждением
- Ссылки (URL) под каждым блоком — откуда взято
- Русский язык; факты — без пометки, догадки — с пометкой `[вывод]`
- Если данных нет — прямо писать «данных недостаточно», не выдумывать
- Сохранить файл через `Write` по указанному пути
- В конце вернуть 5–10 строк резюме того, что собрал

**Агент 1 — Сайт, продукты, ценообразование** → `01_product_pricing.md`
Каталог/линейка продуктов, тарифы и тарифные сетки, must-be vs performance фичи (Kano), ценовой сегмент, мобильное приложение (если есть), upsale/cross-sale на сайте, как монетизация устроена.

**Агент 2 — Стратегия и планы** → `02_strategy_team.md`
Открытые вакансии (HH, LinkedIn, Careers-страница) → планы найма и приоритеты. Блог компании, выступления/интервью CEO и ключевых сотрудников. Roadmap (если в открытом доступе). Партнёрства на сайте. Wayback Machine (archive.org) — как сайт менялся, от чего отказались.

**Агент 3 — Финансы и метрики** → `03_finance_traffic.md`
Выручка: investor relations / отчёты на сайте, для РФ — открытые данные ЕГРЮЛ (если есть ИНН), статьи о раундах, оценки в медиа. Crunchbase раунды (открытые данные). Оценка трафика сайта — открытые данные SimilarWeb (топ-страны, общий объём, соотношение каналов). Бенчмарки по индустрии.

**Агент 4 — ЦА и конкурентное поле** → `04_audience_market.md`
Кейсы клиентов и логотипы на сайте → кто покупает (B2B/B2C, сегменты, размеры). Персоны на лендингах, в FAQ, в блоге. УТП и формулировки JTBD-работ. Отзывы (Otzovik/iRecommend для RU, G2/Trustpilot/Reddit для глобал) — что хвалят, что ругают. Упоминания в соцсетях и медиа (через WebSearch). **Конкурентное поле**: найти 5–10 близких конкурентов через keywords/категории/SimilarWeb-аналоги — короткий список с одной строкой описания каждого.

## Шаг 3. Синтез → итоговый файл

Прочитать все 4 файла и написать `competitor_analysis.md` по шаблону [references/output-template.md](references/output-template.md).

Алгоритм синтеза:

1. **TL;DR** (5–7 строк): кто, на каком рынке, чем берёт, ключевые цифры/факты
2. **Продуктовая линейка и ценообразование** — что продаёт, по какой цене, как монетизирует, must-be vs performance фичи
3. **Стратегия и планы** — куда движется (по вакансиям, блогу, интервью), что недавно поменяли, партнёрства
4. **Финансы и метрики** — выручка/оценка/раунды (если найдено), оценка трафика, динамика. Если данных мало — честно `[данных недостаточно]`
5. **ЦА** — сегменты, типичные клиенты (B2B/B2C, размер, индустрия), JTBD-работы, что хвалят/ругают в отзывах
6. **Рыночное поле** — 5–10 близких конкурентов с короткими дескрипторами, позиция нашего конкурента в этом поле `[вывод]`
7. **Сильные и слабые стороны** `[вывод]` — на основе всего собранного, со ссылкой на конкретные факты выше
8. **Возможности для нас** `[вывод]` — если в инпуте была бизнес-задача, акценты под неё; иначе — общие наблюдения о пробелах/возможностях

## Правила синтеза

- Каждое утверждение — с цитатой или ссылкой на источник
- Выводы помечать `[вывод]`, факты — без пометки
- Если данных мало — прямо писать «данных недостаточно», не выдумывать цифры
- Финальный файл самодостаточен: читается без открытия четырёх исходников
- В конце — мета: дата сбора, источники, оговорки по полноте данных
