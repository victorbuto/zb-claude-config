# Промпты параллельных агентов

Все 4 агента запускаются в одном сообщении (параллельно), `subagent_type="general-purpose"`. Каждый сам пишет результат в свой файл через `Write` и возвращает 5–10 строк резюме.

## Общие требования (для всех 4 агентов)

- Использовать `WebSearch` и `WebFetch` для сбора данных
- Под каждым утверждением — цитата/конкретный факт + ссылка-источник (URL)
- Русский язык. Факты — без пометки, догадки — с пометкой `[вывод]`
- Если данных нет — прямо писать «данных недостаточно», не выдумывать цифры/имена/факты
- Сохранить результат через `Write` по указанному пути
- Вернуть 5–10 строк резюме того, что собрал, и какие были пробелы

## Агент 1 — Сайт, продукты, ценообразование

**Файл:** `01_product_pricing.md`

**Что собирать:**

1. **Линейка продуктов / каталог**
   - Все продукты/сервисы из главного меню и каталога
   - Краткое описание каждого (1 строка)
   - Категории/группировка
   - Мобильное приложение (есть/нет, ссылки на App Store / Google Play)

2. **Тарифы и тарифная сетка**
   - Все тарифы с ценами (в валюте сайта)
   - Что входит в каждый тариф (по фичам)
   - Триал, freemium, скидки за период
   - Для B2B: если цены не указаны → пометить «по запросу», попытаться найти упоминания цен в обзорах/статьях

3. **Анализ фич по Kano**
   - **Must-be** — фичи во всех тарифах (базовая ценность)
   - **Performance** — фичи, которые появляются с ростом тарифа (увеличивают ценность)
   - **Delighters** `[вывод]` — необычные фичи, которые редко встретишь у других

4. **Ценовой сегмент** `[вывод]`
   - Эконом / средний / премиум
   - На основе сравнения с известными аналогами в категории

5. **Монетизация**
   - Как устроена: подписка / разовая покупка / freemium / pay-per-use / комиссия
   - Upsale и cross-sale: что предлагают после покупки, бандлы со скидкой
   - Стоимость владения целиком (особенно для B2B): поддержка, лицензия, доставка, обучение

**Источники:**
- Сайт компании: главная, продуктовые страницы, /pricing, /tariffs, /plans
- Sensor Tower / App Store / Google Play (для приложений) — ценообразование внутри приложения
- Обзоры на сторонних сайтах (G2, Habr, vc.ru) — упоминания цен

## Агент 2 — Стратегия и планы

**Файл:** `02_strategy_team.md`

**Что собирать:**

1. **Открытые вакансии** → планы найма и приоритеты
   - HH.ru, hh.kz, Habr Career (RU)
   - LinkedIn Jobs, careers-страница на сайте (глобал)
   - Какие позиции открыты, в каких командах, сколько
   - Что это говорит о приоритетах: например, много мобильных разработчиков → акцент на mobile; много sales в Бразилии → выход на BR-рынок

2. **Блог и медиа**
   - Главные темы блога компании за последние 6 месяцев
   - Тон: про продукт / про индустрию / про команду / про метрики
   - Заявления о планах, новых фичах, экспансии

3. **Интервью и выступления**
   - Поиск: «[имя CEO] интервью», «[company] founder interview», «[company] roadmap»
   - YouTube, подкасты, vc.ru, Forbes, Inc, RB.ru (для RU)
   - Что говорят про планы, видение, рынок, конкурентов

4. **Roadmap (если открытый)**
   - Поиск «[company] roadmap», «[company] product roadmap»
   - Часто бывает у dev-tools и open-source: GitHub, документация, /roadmap на сайте

5. **Партнёрства**
   - Раздел Partners / Integrations / Customers на сайте
   - Анонсы партнёрств в блоге и медиа за последний год

6. **Wayback Machine (archive.org)**
   - Как сайт менялся за последний год: главная страница, /pricing, продуктовые страницы
   - От чего отказались (продукты, фичи, рынки)
   - Что появилось нового

**Что говорит о стратегии** `[вывод]`:
- Куда движется компания (новые продукты / рынки / сегменты)
- Что приоритизирует (по найму и блогу)
- Что отбросила (по archive.org)

## Агент 3 — Финансы и метрики

**Файл:** `03_finance_traffic.md`

**Что собирать:**

1. **Выручка и финансы**
   - Investor Relations / Annual Report на сайте (для публичных)
   - Поиск: «[company] revenue», «[company] выручка», «[company] финансовые показатели»
   - Для РФ — открытые данные ЕГРЮЛ (если есть ИНН): выручка, прибыль, динамика
   - Если выручка не публикуется — оценка через `кол-во клиентов × средний чек` (если есть данные)

2. **Раунды инвестиций**
   - Crunchbase (открытые данные без логина: общая инфа, последний раунд, инвесторы)
   - Поиск: «[company] raised», «[company] Series», «[company] funding»
   - TechCrunch, vc.ru, RB.ru — статьи про раунды
   - Сумма, дата, оценка (valuation), лид-инвестор

3. **Оценка трафика сайта**
   - SimilarWeb (открытые данные без триала): общий трафик/мес, топ-5 стран, источники трафика (search/direct/social/referral)
   - Альтернатива: SemRush открытые данные
   - Динамика за последние 3–6 месяцев (если видно)

4. **Метрики приложения** (если есть)
   - Поиск: «[app] MAU», «[app] DAU», «[app] users»
   - App Store / Google Play: количество отзывов, средний рейтинг, порядок установок
   - Sensor Tower / data.ai открытые данные

5. **Бенчмарки по индустрии** (опционально, если запрос требует)
   - Поиск: «[категория] industry report», «[категория] benchmarks»
   - Средняя цена клика, конверсия, retention для категории

**Если данных мало:**
- Прямо писать «данных недостаточно» по конкретной метрике
- Не выдумывать цифры
- Указать, какие источники проверены, чтобы было видно, что искали

## Агент 4 — ЦА и конкурентное поле

**Файл:** `04_audience_market.md`

**Что собирать:**

1. **B2B / B2C / Mixed**
   - По описанию продуктов и тону сайта
   - Если mixed — какая доля каждого (если можно оценить)

2. **Кейсы клиентов**
   - Раздел Customers / Cases / Clients / «Нам доверяют» на сайте
   - Логотипы, конкретные кейсы: кто, какая задача, какой результат
   - Размеры компаний (SMB / Mid-market / Enterprise), индустрии, гео

3. **Персоны на лендингах и в блоге**
   - Какие роли упоминаются (маркетолог / разработчик / финдир / основатель / SMM)
   - Какие проблемы им адресует продукт
   - Какие персоны в креативах и описаниях

4. **JTBD-работы и УТП**
   - Главный УТП с главной страницы — какую работу закрывает
   - Дополнительные УТП с продуктовых страниц
   - Сводка JTBD: на что делается акцент

5. **FAQ и барьеры**
   - Раздел FAQ/Help/Knowledge Base
   - Какие вопросы там → какие барьеры у пользователей перед покупкой

6. **Отзывы**
   - Для RU: Otzovik, iRecommend, Яндекс.Отзывы, vc.ru комментарии
   - Для глобал: G2, Trustpilot, Capterra, Reddit (subreddit категории), Product Hunt
   - Что хвалят чаще всего, что ругают чаще всего
   - 3–5 цитат-доказательств с обеих сторон

7. **Упоминания в соцсетях и медиа**
   - WebSearch: «[company]» + Twitter/Reddit/vc.ru/Habr
   - В каком ключе упоминают (положительно / негативно / нейтрально), кто упоминает (клиенты / журналисты / эксперты)

8. **Конкурентное поле — 5–10 близких конкурентов**
   - Поиск аналогов через keywords компании, категорию рынка
   - Источники: Crunchbase «similar companies», SimilarWeb «competitors», Product Hunt категории, G2 «alternatives to [company]»
   - Список: название + URL + 1 строка описания + чем отличается от анализируемого конкурента
   - Позиция нашего конкурента в этом поле `[вывод]`: лидер / челленджер / нишевой / последователь
