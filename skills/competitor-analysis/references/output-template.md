# Шаблон competitor_analysis.md

Использовать как структуру для финального синтеза. Заполнять каждый блок на основе материалов 4 агентов. Каждое утверждение — с цитатой/ссылкой. Выводы — с пометкой `[вывод]`. Если данных нет — `[данных недостаточно]`.

---

```markdown
# Анализ конкурента: [Название компании]

**Дата анализа:** YYYY-MM-DD
**URL:** https://example.com
**Бизнес-задача:** [если была указана; иначе — «общий desk research»]

---

## TL;DR

5–7 строк: кто, на каком рынке, чем берёт, ключевые цифры/факты, главный вывод.

---

## 1. Продуктовая линейка и ценообразование

**Линейка:** список продуктов / категорий / ключевых SKU.

**Тарифы:** таблица или список с ценами. Триал, freemium, скидки.

**Ценовой сегмент:** [эконом / средний / премиум] `[вывод]` — на основании сравнения с [аналог 1, аналог 2].

**Монетизация:** подписка / разовая покупка / freemium / комиссия. Upsale-механики.

**Must-be фичи:** что есть во всех тарифах.
**Performance фичи:** что появляется с ростом тарифа.
**Delighters** `[вывод]`: необычные фичи, которые выделяют продукт.

*Источники:* [ссылки]

---

## 2. Стратегия и планы

**Куда движется** `[вывод]`: вывод из вакансий + блога + интервью.

**Найм:** какие команды растят (X маркетологов на BR-рынок, Y мобильных разработчиков, Z sales-лидов в EU).

**Заявления о планах:** цитаты из интервью CEO / блога / релизов.

**Партнёрства за последний год:** [список с ссылками].

**Что менялось** (по archive.org): что появилось нового на сайте, что убрали.

*Источники:* [ссылки]

**Трафик сайта:** ~X посещений/мес, топ-страны: [список], доли каналов: search X% / direct Y% / social Z%.

**Метрики приложения** (если применимо): MAU/DAU, рейтинг, кол-во отзывов, оценка установок.
```

## Правила заполнения

- Каждый факт — с цитатой/ссылкой на источник прямо в тексте или сразу после блока
- Выводы (`[вывод]`) — отдельно от фактов, с обоснованием на основе фактов выше
- Если по разделу мало данных — `[данных недостаточно: проверены источники X, Y, Z]`
- Финальный документ должен читаться без открытия 4 исходников
- Объём — 2–4 страницы текста (без перегруза, но с конкретикой)
