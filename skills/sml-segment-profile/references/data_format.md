# Формат SML-данных

## Источник

CSV — результат работы инструмента **brand-analytics-segmenter** (Виктор Буто). Размечает посты из соцсетей по 18+ методам через Claude API.

Типичный путь: `data raw/combined_consolidated.csv` или `runs/<дата>/files/*/output.csv`.

## Структура колонок

CSV содержит три блока колонок:

### 1. Колонки исходного источника (не для анализа)
`Дата`, `Текст`, `Источник`, `Url`, `Тип источника`, `Тип сообщения`, `Сюжет`, `Автор`, `Url автора`, `Пол`, `Возраст`, `Аудитория`, `Комментариев`, `Цитируемость СМИ`, `Репостов`, `Лайков`, `Вовлеченность`, `Просмотров`, `Тональность`, `Роль объекта`, `Агрессия`, `Страна`, `Регион`, `Город`, `Язык`, `WOM`.

Из них в анализе используются: `Текст`, `Тональность`. Остальные — служебные.

### 2. Доп. колонки разметки (не метод)
`Продукты` (разделитель ` | `), `Тип продукта` (разделитель ` | `), `Ценность` (значения: `высокая`/`средняя`/`низкая`), `Все сегменты` (сводка).

### 3. Колонки методов (главное для анализа)

Каждый метод — отдельная колонка. Значения разделены ` ; ` (с пробелами). Может быть пусто.

**Полный список методов:**
- `Социально-демографический` — пол, возраст, семейный статус
- `Социально-экономический` — профессия / роль
- `География` — страна / регион / город
- `Интересы` — хобби, увлечения
- `Проблемы` — высказанные негативные ситуации
- `Индустрия` — для B2B
- `Размер компании` — для B2B
- `Ценовая категория` — бюджетный / миддл / премиум / люкс
- `ЛПР` — лицо принимающее решение
- `Контекст потребления` — когда / в каких условиях используют (зима, жара, кожа, путешествие)
- `Технология` — технологические аспекты
- `Ценности` — что важно
- `Психотипы` — типажи
- `JTBD` — задача, которую решает продукт
- `Потребности` — конкретные ожидания от продукта
- `Привычки` — повторяющееся поведение
- `Кривая инноваций` — новатор / ранний последователь / большинство
- `Триггеры` — что запускает покупку
- `Value chain` — этап взаимодействия с категорией
- `Стиль жизни`
- `Опыт в категории` — глубина опыта

## Особенности данных

- Разделитель внутри ячейки метода: `"; "` (с пробелами).
- Разделитель в `Продукты` и `Тип продукта`: `" | "` (с пробелами).
- Значения уже нормализованы в lowercase (если прошла консолидация).
- Колонки могут отсутствовать в конкретном CSV — проверять `df.columns` перед использованием.
- `segments_count` — сколько методов с непустым значением для строки.

## Распределение размеченности

В типичном бьюти-датасете:
- Большие колонки: `Потребности` (1411/3659 строк), `Привычки` (1171), `Контекст потребления` (988), `JTBD` (810)
- Средние: `Value chain` (689), `Опыт в категории` (581), `Триггеры` (283), `Проблемы` (266)
- Малые: `Ценности` (123), `Стиль жизни` (97), `Социально-демографический` (42)

**Внимание:** `Проблемы` всегда сильно недосчитаны (см. methodology.md — жанр обзоров).

## Технические лимиты при чтении

Файл подвыборки 200+ строк в compact-формате — это 300-500KB и 4000+ строк. При чтении через Read tool:
- Лимит: 256KB / 25000 токенов на запрос
- При больших файлах читать чанками по `offset=N --limit=700`
- 4 захода обычно покрывают весь файл

Если в подвыборке 100 строк или меньше — обычно влезает в одно чтение.
