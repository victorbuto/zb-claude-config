# Operational Rules

Правила, накопленные из QA-аудитов реальных прогонов. Проверяй этот файл при планировании запросов (Phase 2) и при выполнении поиска (Phase 3).

---

## Tool Selection Rules

1. **Reddit бесполезен для нишевых российских брендов.** Если бренд российский и малоизвестен глобально — не использовать Reddit. Альтернативы: pikabu.ru, dzen.ru, otzovik.com, irecommend.ru.
   - *Источник: тест LIME 2026-04-21 — Q11 вернул Lime Crime (косметика) вместо LIME (одежда)*

2. **Проверять URL перед tavily_crawl.** Перед запуском crawl сделать поисковый запрос `[бренд] официальный сайт`, чтобы убедиться в правильности домена. Crawl на неверный URL = потерянный запрос.
   - *Источник: тест LIME 2026-04-21 — limeshop.ru оказался неверным, правильный домен lime-shop.com*

3. **Не ставить userLocation: US для российских тем.** Если тема исследования — Россия, параметр userLocation должен быть опущен или установлен в RU. US уводит выдачу от российского контекста.
   - *Источник: тест LIME 2026-04-21 — Q9 вернул только 2 результата вместо 10*

4. **Exa `category="financial report"` бесполезна для нишевого FMCG market-sizing.** Возвращает крупнокап SEC-филинги (Kraft Heinz, PepsiCo, Stryker), не отраслевые market-reports. Для объёмов/долей рынка нишевой категории использовать `category="research paper"` или tavily_search.
   - *Источник: тренд-рисёрч рыба/морепродукты 2026-07-19 — Q6/Q30/Q37 провалились дважды, фолбэк на tavily сработал*

5. **Exa `type`: в текущей сборке валидны только `auto`/`fast`/`instant`, НЕ `neural`.** Ставить `type="auto"` (рекомендованный высококачественный режим). `type="neural"` отклоняется.
   - *Источник: тренд-рисёрч рыба/морепродукты 2026-07-19*

6. **Exa `includeDomains` — мягкий, не строгий фильтр.** Выдача может содержать домены вне списка. Не полагаться как на жёсткое ограничение; при необходимости точного среза — доп-фильтрация или tavily `include_domains`.
   - *Источник: тренд-рисёрч рыба/морепродукты 2026-07-19 — Q45 с rbc.ru/kommersant.ru вернул также retail.ru, sfera.fm*

7. **Для азиатских трендов слайсы на CJK-языках обязательны.** Запросы на 中文/한국어/日本語 (`海鲜预制菜`, `수산 간편식`, `魚離れ`, `骨なし魚`) дают уникальные сигналы, которых нет в англоязычной выдаче. Ставить `userLocation` страны (CN/KR/JP).
   - *Источник: тренд-рисёрч рыба/морепродукты 2026-07-19 — азиатский HMR/предзаготовки найдены только через родной язык*

8. **«Имя источника в ключе» надёжно НЕ для всех.** Работает: FMI, Circana, NielsenIQ, Pinterest Predicts, SPINS, McKinsey, Deloitte. Молчит по своей нише (уходит на адженсы): Trendhunter, Springwise, Kantar Worldpanel, TrendWatching — по ним искать через смежные издания (Folio3, Mintel, Mordor, Innova).
   - *Источник: тренд-рисёрч рыба/морепродукты 2026-07-19*
