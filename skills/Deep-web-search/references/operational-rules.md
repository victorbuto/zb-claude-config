# Operational Rules

Правила, накопленные из QA-аудитов реальных прогонов. Проверяй этот файл при планировании запросов (Phase 2) и при выполнении поиска (Phase 3).

---

## Tool Selection Rules

1. **Reddit бесполезен для нишевых российских брендов.** Если бренд российский и малоизвестен глобально — не использовать Reddit. Альтернативы: pikabu.ru, dzen.ru, otzovik.com, irecommend.ru.
   - *Источник: тест LIME 2026-04-21 — Q11 вернул Lime Crime (косметика) вместо LIME (одежда)*

2. **Проверять URL перед tavily_crawl.** Перед запуском crawl сделать поисковый запрос `[бренд] официальный сайт`, чтобы убедиться в правильности домена. Crawl на неверный URL = потерянный запрос.
   - *Источник: тест LIME 2026-04-21 — limeshop.ru оказался неверным, правильный домен lime-shop.com*

3. **Не ставить userLocation: US для российских тем.** Если тема исследования — Россия, параметр userLocation должен быть опущен или установлен в RU. US уводит выдачу от российского контекста.
   - *Источник: тест LIME 2026-04-21 — Q9 вернул только 2 результата вместо 10*
