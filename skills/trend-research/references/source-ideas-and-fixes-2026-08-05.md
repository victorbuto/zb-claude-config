## 1.5 Пейволы и «именованные источники»

- **Пейвол-вендоры** (Skift Global Outlook 403, Statista, Euromonitor, РБК Pro, INFOLine, BusinesStat, Mintel): целить не в отчёт, а в новостной пересказ с цифрой — CNBC, Reuters, Fortune, Ведомости цитируют. Плюс пресс-релиз, демо-PDF, Wayback-снимок. Никогда не тратить слот на основной URL.
- **«Имя источника в ключе»** работает избирательно. Надёжно: FMI, Circana, NielsenIQ, Pinterest, SPINS. Ненадёжно (не поднимают свой контент): Trendhunter, Springwise, Kantar Worldpanel, TrendWatching — под них нужен прямой обход сайта или RSS, не поисковый запрос.
- **NielsenIQ/GfK как keyword по РФ** — score 0.082, данные закрыты. Искать через отраслевые СМИ, которые их цитируют.

## 1.6 Формулировки ключей — накопленные правила

| Антипаттерн | Замена |
|---|---|
| `тренды рынка X` (РФ) → 0 сигналов | `[аналитик] [метрика] [сегмент] [год]` |
| `best practices` → популярные блоги без данных | `case study + N%`, `benchmark + dataset`, имя автора + год |
| Абстрактные существительные (`atmosphere`, `vibe`, `context engineering`) | Конкретные артефакты (`flat`, `ritual`, `zine`, `dress code`) |
| Год «2026» в ключе без фильтра даты | Год только в паре с `startPublishedDate`, иначе выкидывать |
| Две персоны в одном запросе (MrBeast + Brockman, Bengio/LeCun) | Одна персона = один запрос |
| Peristatic-фраза без платформы/ниши | Всегда добавлять платформу или нишу |
| Один запрос на азиатский регион | Минимум 2–3 на регион (продукт + промо + потребитель), на родном языке |

**Лучшие подтверждённые шаблоны:** `[topic] taxonomy categories archetypes types` (Taxonomy Pattern, лучший hit rate по нескольким прогонам); `[subject] [institution] [founder name] history` (ethnographic master source); «именованный артефакт + концептуальный термин» (8/8 на AGI-прогоне); CJK-слайсы на родном языке.

## 1.7 Два бага процесса

1. **Fallback объявлен, но не срабатывает.** В прогонах 2026-04-22, 2026-06-03, 2026-06-26 порог был заслужен (score < 0.3), но переключения не произошло. Нужен не совет, а жёсткое правило в коде/чек-листе: `max score < 0.3` или `useful < 50%` → автоматический второй проход другим инструментом.
2. **Перепутанные file ID при параллельных запросах** (2026-06-29, Q17/Q18) — риск приписать цитату чужому источнику. Изолировать пространство ID на запрос и сверять «источник ↔ запрос» перед записью сигнала.

# Часть 2. Банк идей по источникам

Организовано по вопросу, на который источник отвечает. Колонка «дырка» — чего сейчас в скилле нет.

## A. Соцплатформы через API вместо поиска

Сейчас в скилле соцсети покрыты только `yt-parser` и Reddit RSS. Это самый большой недобор: поиск по вебу не видит внутрь платформ.

| Платформа | Канал доступа | Что даёт для трендов | Дырка |
|---|---|---|---|
| **YouTube Data API v3** | Официальный, бесплатный. Квота 10 000 юнитов/сутки; `search.list` = 100 юнитов, `videos.list` / `commentThreads` = 1. **С июня 2026 у новых проектов отдельный бакет — 100 search-вызовов в день**, остальные методы делят общий пул | Взлёт темы по датам публикации, отношение просмотров к возрасту канала (outlier-скор), заголовки как язык аудитории, комментарии как возражения | Есть `yt-parser`, но он на своём пути. Официальный API даёт статистику канала и комментарии дёшево (1 юнит) |
| **YouTube транскрипты** | Недокументированный, но стабильный XML-эндпоинт субтитров — **не тратит квоту**; либо `yt-dlp --write-auto-sub`; либо ScrapeCreators `v1_youtube_video_transcript` | Дословная лексика ниши, аргументы, структура объяснений — сырьё под формулировки трендов и под твои видео об истории идей | Транскрипты не заведены как отдельный класс источника |
| **Reddit Data API** | Бесплатно для некоммерческого использования: 100 QPM с OAuth, ~10 QPM без. Самообслуживание закрыто — новый OAuth-клиент через ручное одобрение, 2–4 недели. Коммерческий тариф — от $12 000/мес | То же, что RSS, но с сортировкой, временными окнами и стабильными лимитами вместо 429 | Текущий пайплайн на RSS+shreddit: 429 и тихие фолбэки |
| **Arctic Shift** | Бесплатно, без авторизации, ~120K запросов/час, архив 2005→2026 | Когда тема впервые всплыла и как росла — ретроспектива, которой RSS не даёт | Полностью отсутствует |
| **Pushshift / PullPush** | Запасной архивный канал | То же, медленнее, с провалами | — |
| **TikTok Research API** | Бесплатно, но только для аффилированных с некоммерческим вузом, ~4 недели одобрения, 1000 запросов/сутки, коммерческое использование запрещено | Формально закрыт для агентства | Не рассматривать; идти через сторонние API |
| **TikTok через сторонние** | ScrapeCreators (уже подключён), Apify, EnsembleData, Lamatok, Bright Data | Хештеги, звуки, тренд-фид, комментарии, транскрипты, поиск по ключу | TikTok в скилле не покрыт вообще |
| **Instagram / Threads** | ScrapeCreators; Instagram Graph API для своих аккаунтов | Reels-тренды, хештеги, визуальный язык категории | Не покрыт |
| **X / Twitter** | X API v2 (Basic ~$200/мес), либо ScrapeCreators `v1_twitter_*`, либо xAI/Grok-поиск | Ранние дискуссии, реакции индустрии | Не покрыт |
| **LinkedIn** | ScrapeCreators `v1_linkedin_company_posts`, `v1_linkedin_search_posts` | B2B-повестка, как компании сами говорят о сдвиге, вакансии как сигнал | Не покрыт |
| **Bluesky** | Публичный AT Protocol API, бесплатно | Миграция части техно/медиа-аудитории | Не покрыт |
| **Pinterest** | Pinterest Trends (публичный), ScrapeCreators `v1_pinterest_search` | Ранние визуальные и лайфстайл-тренды, сезонность спроса на эстетику | Pinterest назван в логе как «сработал» — но без тулинга |
| **VK / Одноклассники** | VK API (бесплатно по токену), `newsfeed.search`, `wall.get` | Единственный массовый РФ-соцканал с открытым API — сейчас в скилле только Telegram | Не покрыт, крупная дырка для РФ |
| **Rutube / Дзен** | Скрейп, RSS Дзена | РФ-видео и лонгриды, аудитория вне YouTube | Не покрыт |

| **Discord / Slack-сообщества** | Публичные серверы, экспорт | Профессиональные ниши, где обсуждение не выходит в веб | Не покрыт |
| **Spotify / подкасты** | ScrapeCreators `v1_spotify_podcast_episodes`; Listen Notes API | Описания эпизодов как карта повестки; гости как карта экспертов | Не покрыт |

## B. Отраслевая пресса как отдельный класс источника

По логам это подтверждённая жила (авиа-прогон: Skift, SimpleFlying, RunwayGirl, AeroTime, ThePointsGuy дали больше, чем универсальные трендрепорты), но в скилле она не выделена в отдельный слой и собирается разово поиском.

**Что сделать классом, а не разовым запросом:**

| Приём | Как | Зачем |
|---|---|---|
| **Карта trade press под категорию** | Первый шаг любого прогона: запрос `[category] trade publication OR industry magazine` + проверка через Similarweb/Wikipedia | Логи показывают: под нишевую категорию профильное издание >> универсальный трендрепорт |
| **RSSHub** | Селф-хост на Railway (уже есть), 5000+ маршрутов | Превращает издание без RSS в поток; закрывает и авторов, и YouTube-каналы, и Telegram |
| **Google News RSS** | `news.google.com/rss/search?q=...&hl=ru&gl=RU` — бесплатно, без ключа | Дешёвый мониторинг по ключу и по изданию, поддерживает операторы `site:`, `when:7d` |
| **Bing News / NewsAPI / GNews / Currents** | API с бесплатным тиром | Второй новостной канал для сверки |
| **GDELT DOC 2.0** | Бесплатно, обновление каждые 15 мин, есть выгрузка в BigQuery | Единственный способ увидеть **объём и тональность освещения темы во времени и по странам** — это и есть доказательство тренда, а не мнение |
| **Media Cloud** | Бесплатно, академический | Тематический анализ по корпусу изданий |
| **РФ-отраслевые** | Retail.ru, Infoline, Sostav, AdIndex, Cossa, Adpass, VC, Sfera.fm, Fishnews, Профиль по вертикали | По логам — жила для РФ-фактуры; PDF-журналы (Fishnews) требуют парсинга |
| **Отраслевые ассоциации** | АКАР, АКИТ, РАЭК, РСТ, АТОР, Ассоциация компаний интернет-торговли; глобально — FMI, IAB, WFA | Публикуют бесплатные срезы рынка с цифрами; по логам «имя источника в ключе» работает для FMI/Circana |

## C. Рекламные библиотеки — недоиспользованный слой

Для брендингового агентства это прямой доступ к тому, **что бренды реально говорят**, без пейвола. В скилле не упомянуто вообще.

| Источник | Доступ | Что даёт |
|---|---|---|
| **Meta Ad Library** | Официальный публичный API + ScrapeCreators `v1_facebook_adLibrary_*` | Все активные креативы бренда и конкурентов, даты запуска, тексты, транскрипты видео. Позволяет датировать смену коммуникации |
| **TikTok Creative Center / Ad Library** | Публичный + ScrapeCreators `v1_tiktok_ad_library_*` | Топ-креативы по категории и стране, тренды звуков и хуков |
| **Google Ads Transparency Center** | Публичный + ScrapeCreators `v1_google_company_ads` | Кто и что рекламирует, включая РФ-бренды за рубежом |
| **LinkedIn Ads Library** | ScrapeCreators `v1_linkedin_ads_search` | B2B-позиционирование |
| **AdIndex / Sostav / Рекламные премии** | Веб | РФ-кейсы и бенчмарки креатива |

**Приём:** «диахронический срез рекламы» — вытащить креативы категории за 2023 и за 2026, сравнить обещания. Это доказательство сдвига позиционирования, а не цитата аналитика.

## D. Спрос и внимание (количественные прокси)

| Источник | Доступ | Что даёт | Статус |
|---|---|---|---|
| **Google Trends** | `gtrends-parser` (неофициальный путь) + официальный Trends API в альфе по заявке | Динамика, RISING-запросы как ранний сигнал, география | Есть, но на неофициальном пути — стоит подать заявку на официальный |
| **Яндекс Вордстат API** | **Открыт в 2026, бесплатный, бета по заявке.** Частотность, топ похожих формулировок, динамика, срезы по регионам/устройствам/периодам | Прямой РФ-аналог Google Trends с абсолютными числами — то, чего в скилле нет совсем. # Часть 4. Приоритет внедрения

**Уровень 1 — доступ уже есть, только прописать в SKILL.md (день работы):**
1. ScrapeCreators MCP как основной канал соцплатформ. Reddit-пайплайн перевести на него, старый оставить фолбэком.
2. Firecrawl `scrape`/`map` — вместо провальных `tavily_crawl` и `tavily_extract`-как-поиск.
3. Рекламные библиотеки как отдельный вариант поиска (пятый) — прямо под профиль ONY.
4. Жёсткие пороги фолбэка и пост-фильтр релевантности в Reddit-скрипте — чинит «тихий отказ».

**Уровень 2 — бесплатно, нужен небольшой код в `trend_sources.py`:**
5. **Яндекс Вордстат API** — подать заявку, это главный недостающий РФ-инструмент спроса.
6. GDELT — объём и тональность освещения во времени.
7. Wikipedia Pageviews — дешёвый прокси внимания.
8. OpenAlex — научный фронт по годам.
9. Google News RSS — мониторинг отраслевой прессы без ключа.
10. Wayback CDX — доказательство сдвига диффами.
11. Arctic Shift — ретроспектива Reddit.

**Уровень 3 — инфраструктура:**
12. RSSHub на Railway — отраслевая пресса из разового поиска в накопительный поток.
13. Docling — 205 PDF-отчётов в оборот.
14. YouTube Data API v3 официально (с учётом нового бакета 100 search/сутки — планировать запросы, тяжёлый `search.list` экономить, `videos.list` и `commentThreads` по 1 юниту использовать свободно).

**Уровень 4 — платное, под конкретный проект:**
15. MPStats API — когда категория продаётся на маркетплейсах.
16. X API Basic / TGStat API — под медийные темы.

**Правки в файлы скилла:**
- `SKILL.md`: пятый вариант поиска — рекламные библиотеки; шестой — платформенные API. Жёсткое правило фолбэка. Запрет `financial report` и `type=neural`.
- `references/sources.md`: блоки «отраслевая пресса по вертикалям», «рекламные библиотеки», «спрос и внимание», «наука и патенты». Понизить Trendhunter/Springwise/Kantar/TrendWatching как «не искать по имени».
- `references/conditional-sources.md`: добавить ScrapeCreators-маршруты в таблицу маршрутизации.
- `scripts/trend_sources.py`: пост-фильтр релевантности, последовательный запуск с паузами, честный `--days`, новые подкоманды `gdelt`, `wikipedia`, `openalex`, `wayback`, `arcticshift`.
