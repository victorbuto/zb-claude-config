# Яндекс Вордстат API: установка и использование

**Обновлено:** 2026-08-05
**Назначение:** подключить Вордстат как источник РФ-спроса в `trend-research` и объяснить, как читать его выдачу в трендовой логике.
**Описание:** порядок получения ключа, переменные окружения, команды парсера, известные грабли API и правила интерпретации.
**Парсер:** `vibecode_projects/wordstat-parser/` (отдельный проект, как `gtrends-parser` и `yt-parser`). Технические детали и Features — в его `README.md`, здесь только то, что нужно скиллу.

---

## 1. Что это даёт

Единственный инструмент, который показывает **российский спрос в абсолютных числах**, а не в относительном индексе. Google Trends по РФ показывает форму кривой, Вордстат — сколько людей реально это ищут.

Три среза:
- **Динамика** — частотность по месяцам. Это доказательство роста или спада категории.
- **Топ-фразы и ассоциации** — дословный язык спроса. Прямое сырьё под JTBD и формулировки сегментов.
- **Регионы** — где тема горячее среднего (индекс аффинити > 100).

## 2. Получить доступ (10 минут, разово)

Вордстат переехал: раньше его API просили через поддержку Директа, теперь он живёт **внутри Yandex Search API в Yandex Cloud**. Заявка и одобрение не нужны — нужен обычный аккаунт в облаке.

1. Зайти на **[aistudio.yandex.ru](https://aistudio.yandex.ru)** под своим Яндекс ID. Если облака ещё нет — оно создастся вместе с платёжным аккаунтом.
2. Создать **API-ключ** в AI Studio. Это самый короткий путь: у ключа AI Studio уже есть все нужные роли, отдельный сервисный аккаунт настраивать не надо.
3. Скопировать **folder ID** — идентификатор каталога, он виден в адресной строке консоли (`.../folders/b1g...`) или на странице каталога.
4. Проверить, что на каталоге стоит роль **`search-api.webSearch.user`**. Если делал через AI Studio-ключ, она уже есть. Если собираешь сервисный аккаунт руками — это самая частая причина ошибки 403.

**Про деньги:** Search API тарифицируется поштучно, единица — один запрос. Запросы, упавшие с ошибкой авторизации или внутренней ошибкой сервера, не тарифицируются, ночью с 00:00 до 08:00 МСК на часть типов запросов действует скидка. Практические лимиты — порядка 10 запросов в секунду и 1000 в сутки. Для трендвотчинга это много: полный `probe` по ключу — это 3 запроса. Точный прайс смотри в консоли перед первым большим прогоном.

---

## 3. Прописать ключи

Добавить в `~/.zshrc`:

```bash
export YANDEX_SEARCH_API_KEY="<ключ из AI Studio>"
export YANDEX_FOLDER_ID="<b1g...>"
```

Затем `source ~/.zshrc`. Скрипт также понимает `YANDEX_IAM_TOKEN` (тогда шлёт `Bearer` вместо `Api-Key`) и запасные имена `YANDEX_API_KEY` / `YANDEX_AI_API_KEY`.

Проверка, что всё встало:

```bash
cd "vibecode_projects/wordstat-parser" && ./run.sh tree --find москва
```

Должен вернуть ID 213. Если 403 — не выдана роль, если 401 — ключ невалиден, если «нет folderId» — не подхватилась переменная.

## 4. Команды

Парсер: `vibecode_projects/wordstat-parser/run.sh`. Только стандартная библиотека, venv не нужен.

| Команда | Что делает | Пример |
|---|---|---|
| `probe` | **Основная.** Один ключ → динамика за 25 месяцев + топ-фразы + ассоциации + регионы + вердикт по росту | `./run.sh probe "доступный премиум" --output signals.json` |
| `compare` | Несколько ключей → рейтинг **по темпу роста**, а не по объёму | `./run.sh compare "экотовары,осознанное потребление,zero waste"` |
| `dynamics` | Только ряд частотности | `./run.sh dynamics "рыбные снеки" --months 36` |
| `top` | Только топ похожих запросов и ассоциации | `./run.sh top "морепродукты" --limit 100` |
| `regions` | Только география с индексом аффинити | `./run.sh regions "доставка рыбы" --scope REGION_CITIES` |
| `tree` | Справочник регионов, поиск ID по названию | `./run.sh tree --find новосиб` |

Общие флаги: `--region` (принимает и ID, и русские названия: `москва`, `спб`), `--device`, `--output`, `--sleep`, `--folder`.

Пример под сегментацию — сравнить, какой из формулировок сегмента растёт спрос:

```bash
python3 scripts/wordstat.py compare "подписка на еду,готовая еда доставка,рацион питания доставка" \
  --months 25 --output /tmp/segment-demand.json
```

В stderr падает короткая сводка глазами, в stdout или файл — полный JSON.

## 5. Как читать выдачу

Скрипт сам считает вердикт по месячному ряду:

| Вердикт | Условие |
|---|---|
| `растёт` | YoY по последним 3 месяцам ≥ +30% |
| `умеренный рост` | +10…+30% |
| `плато` | −15…+10% |
| `падает` | ниже −15% |
| `ниша — объёмов мало` | меньше 1000 запросов в месяц в среднем: читать как шум, не как тренд |

Дополнительно отдаёт `seasonality_spread` — отношение пика к дну. Если разброс больше 2, кривую нельзя читать как тренд без поправки на сезон: сравнивать надо месяц с тем же месяцем год назад, а не с предыдущим.

**Правило атрибуции:** Вордстат — Tier-1 источник (первичные данные с цифрой и датой). Но он показывает **спрос на формулировку**, а не на явление. Рост запроса «квайет лакшери» — это доказательство роста интереса к термину, а не к практике. В синтез тренда класть как один сигнал из нескольких, не как единственный.

## 6. Грабли API

1. **`folderId` обязателен в теле каждого запроса**, не в заголовке. Без него — `INVALID_ARGUMENT`. Скрипт подставляет сам.
2. **Счётчики приходят строками** (int64 в protobuf). Скрипт оборачивает в `int()`, но если пойдёшь в API руками — помни.
3. **Для `PERIOD_MONTHLY` дата конца обязана быть последним днём месяца**, иначе ошибка. Скрипт считает окно сам через `calendar.monthrange`.
4. **Операторы Вордстата не поддерживаются**: `!`, `+`, `[]` в API игнорируются. Точные частотности через API не собрать — только широкое соответствие.
5. **Ассоциации могут быть пустыми** на узких нишах. Это не ошибка.
6. **Фраза — до 400 символов.** Скрипт обрезает.
7. **SSL на macOS** иногда падает на системном Python. Лечится `pip install certifi`; на крайний случай есть флаг `--insecure` — только для локальных прогонов.
8. **429** — упёрся в квоту. Увеличить `--sleep`.
