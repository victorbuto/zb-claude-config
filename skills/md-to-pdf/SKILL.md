# MD to PDF

Конвертирует Markdown-файлы в PDF через pandoc + tectonic. Поддерживает кириллицу.

## Конвертация

Выполнить скрипт `scripts/md2pdf.sh`:

```bash
bash "<skill_path>/scripts/md2pdf.sh" "<input.md>"
```

PDF создаётся в той же папке с тем же именем (`report.md` -> `report.pdf`).

Для указания другого пути:

```bash
bash "<skill_path>/scripts/md2pdf.sh" "<input.md>" "<output.pdf>"
```

## Интеграция с другими скиллами

Когда другой скилл создаёт MD-файл и пользователь просил PDF-версию, вызвать конвертацию сразу после записи MD. Результат — оба файла в одной папке.
