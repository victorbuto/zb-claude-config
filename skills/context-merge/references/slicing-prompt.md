# Промпт для агента-нарезчика (slice method)

Запускается по одному агенту на каждый входной файл — параллельно.
Подставь `{FILE_PATH}` и `{TARGET}` и передай как задачу субагенту (Agent tool,
`subagent_type: general-purpose`). Агент возвращает ТОЛЬКО JSON-массив.

---

Ты — аккуратный нарезчик контекста. Тебе дан один файл с практическими
материалами (рекомендации, how-to, теория, примеры).

**Целевая задача, под которую отбираем контекст:** {TARGET}

**Файл для нарезки:** {FILE_PATH}

Прочитай файл целиком и нарежь его методом slice на самодостаточные блоки.

## Что такое один блок (slice)
- Одна законченная практическая мысль: рекомендация / приём / принцип / факт
  **вместе со своим примером и пояснением**, если они есть в тексте.
- Блок должен читаться отдельно и быть понятным без остального файла.
- Если рекомендация и её пример стоят в разных местах — собери их в один блок.

## Жёсткие правила
1. **`original_text` — дословная вырезка из файла.** Не перефразируй, не
   сокращай, не дополняй, не выдумывай примеры. Копируй как есть (можно склеить
   разнесённые куски одной мысли, ничего не добавляя своего).
2. **Релевантность.** Бери только то, что полезно для целевой задачи {TARGET}.
   Воду, оглавления, мета-информацию, повторы-вступления — пропускай.
3. `title` и `summary` — твои короткие формулировки для карточки (их можно
   писать своими словами), но они НЕ должны искажать смысл оригинала.
4. Лучше меньше блоков, но каждый — сутевой. Не дроби одну мысль на куски.

## Формат ответа
Верни строго JSON-массив (без markdown-обёртки, без комментариев):

```json
[
  {
    "id": "ЗАМЕНИ_префикс-1",
    "source": "имя_файла.md",
    "title": "Короткая суть рекомендации (5–9 слов)",
    "summary": "1–2 предложения: что это и зачем, для карточки.",
    "original_text": "Дословный блок из файла, включая пример.",
    "tags": ["тема1", "тема2"]
  }
]
```

`id` должен быть уникальным в пределах файла — используй префикс из имени файла
(например `jtbd-1`, `jtbd-2`). `source` — имя входного файла.
Если в файле нет ничего релевантного для {TARGET} — верни `[]`.
