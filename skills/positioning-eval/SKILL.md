# Оценка позиционирования бренда

## Workflow

### 1. Получить вводные

Пользователь присылает текстом или файлом: суть бренда, инсайт, positioning statement или бренд-платформу целиком.

Определить, какие вводные уже есть, а каких не хватает. Запросить недостающее из списка:

- **Продукт/услуга** — что именно продает компания
- **Целевая аудитория** — для кого, какой сегмент
- **Бизнес-цели** — что бизнес хочет достичь (рост, ребрендинг, выход на новый рынок и т.д.)
- **Конкуренты** — ключевые игроки в категории
- **Материнский бренд** — если есть, какой и с какими ценностями
- **Существующие бренд-активы** — что уже узнаваемо в бренде (если есть)

Не спрашивать то, что очевидно из присланного. Задать только недостающие вопросы одним сообщением.

### 2. Оценить концепцию

Прочитать [references/criteria.md](references/criteria.md) для полного списка критериев.

Определить, что именно прислали:
- **Суть бренда** → оценить по критериям A1-A5
- **Инсайт** → оценить по критериям B1-B5
- **Positioning statement** → оценить по критериям C + A1-A5
- **Бренд-платформа** → оценить по всем критериям A-D

Оценивать жёстко и честно. Называть проблемы прямо. Не смягчать формулировки.

### 3. Формат ответа

#### Таблица нарушений

Для каждого элемента (суть, инсайт, позиционирование) — отдельная таблица. Включать ТОЛЬКО критерии, по которым есть нарушения или замечания.

```
### [Бренд] — "[формулировка]"

| Критерий | Нарушение |
|----------|-----------|
| **Название критерия** | Конкретное описание проблемы. Почему это плохо, с примером или тестом |
```

Стиль нарушений — конкретный, с тестами:
- Тест на подстановку: «Подставь вместо X любого конкурента — фраза работает»
- Тест «для всех = ни для кого»
- Тест на продукт: «Откуда понятно, что это [категория]?»
- Конкретные антипаттерны из criteria.md

Если по критерию все хорошо — не включать в таблицу.

#### Вердикт

После таблицы — блок с общей оценкой:

```
### Вердикт: [Годно / Доработать / Переделать]

**Что хорошо:** [1-2 предложения, если есть сильные стороны]

**Главная проблема:** [ключевая слабость в одном предложении]
```

Шкала вердиктов:
- **Годно** — концепция рабочая, мелкие замечания
- **Доработать** — есть сильная основа, но нужны конкретные правки
- **Переделать** — фундаментальные проблемы, нужен пересмотр подхода

#### Рекомендации

```
### Что делать дальше

1. [Конкретная стратегическая рекомендация]
2. [Конкретная стратегическая рекомендация]
...
```

Рекомендации должны быть:
- Конкретными действиями, а не абстрактными советами
- Привязаны к найденным проблемам
- Ориентированы на стратегическую работу (исследования, воркшопы, пересмотр ЦА и т.д.), а не на «переформулируйте»

### Язык

Отвечать на языке запроса. Если запрос на русском — оценка на русском.
