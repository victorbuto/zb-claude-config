# Cognitive Bias Detector

Стандарт для поиска когнитивных искажений и ошибок мышления в материалах.

## Каталог искажений

Полный каталог (65 искажений + 10 принципов) с маркерами и примерами:
[references/biases-catalog.md](references/biases-catalog.md)

Загрузить каталог перед анализом.

## Процесс анализа

### 1. Определить тип материала

- **Отчёт / аналитика** — фокус: данные, выборки, причинность, ретроспектива
- **Презентация / питч** — фокус: фрейминг, приманка, WYSIATI, сверхуверенность
- **Стратегия / план** — фокус: планирование, невозвратные затраты, третья альтернатива, опровержимость
- **Идея / гипотеза** — фокус: подтверждение, лжеобъяснение, предсказания, бритва Оккама
- **Аргументация / дискуссия** — фокус: логика, авторитет, ad hominem, стоп-сигналы

### 2. Прогнать чеклист из 20 вопросов

Проверить каждый пункт. Отмечать как найденные искажения, так и отсутствие проблем.

1. **Данные:** Достаточна ли выборка? Нет ли подмены статистики примерами? Базовый процент учтён?
2. **Аргументация:** Нет ли апелляции к авторитету, большинству, новизне, личности?
3. **Отбор информации:** Рассмотрены ли альтернативы? Нет ли избирательного подбора фактов?
4. **Подача:** Как фрейминг влияет на восприятие? Есть ли привязка к нерелевантным числам?
5. **Самооценка:** Нет ли сверхуверенности? Учтены ли риски?
6. **Решения:** Нет ли невозвратных затрат? Не путается ли бездействие с безопасностью?
7. **Люди и группы:** Нет ли стереотипов, проекции, эффекта ореола?
8. **Ретроспектива:** Не выдаётся ли результат за качество решения?
9. **Информационная среда:** Нет ли пузыря? Источники разнообразны?
10. **Подмена:** Не подменён ли сложный вопрос простым?
11. **Привязанность:** Нет ли привязанности к идее? Не являются ли убеждения «кумовскими»?
12. **Нарратив:** Не придуман ли нарратив для оправдания уже принятого решения?
13. **Лжеобъяснения:** Объяснение предсказывает конкретный результат — или работает при любом исходе?
14. **Стоп-сигналы:** Есть ли фразы, после которых прекращается анализ?
15. **Предвзятость поиска:** Не остановился ли поиск на удобном результате?
16. **Изменение позиции:** Менялся ли вывод автора в ходе работы?
17. **Опровержимость:** Какой результат опровергнет вывод? Если ответа нет — модель пустая.
18. **Третья альтернатива:** Рассмотрены ли варианты кроме двух очевидных?
19. **Конкретное предсказание:** Есть ли измеримое ожидание, которое можно проверить?
20. **Слепые зоны:** Нет ли тем, которые автор системно обходит?

### 3. Сформировать отчёт

Формат вывода:

```
## Анализ на когнитивные искажения

**Материал:** [название/описание]
**Тип:** [отчёт / презентация / стратегия / идея / аргументация]

### Найденные искажения

Для каждого найденного искажения:

#### [Номер]. [Название искажения]
- **Где:** конкретная цитата или место в материале
- **Суть:** что именно не так (1-2 предложения)
- **Риск:** к чему может привести (1 предложение)
- **Как исправить:** конкретное действие (1-2 предложения)

### Общая оценка

- **Критичные проблемы:** [список, если есть]
- **Сильные стороны:** [что сделано хорошо]
- **Главная рекомендация:** [одно ключевое действие]
```

## Правила анализа

- Искать реальные искажения, а не натягивать каталог на текст. Если искажения нет — не выдумывать.
- Указывать конкретные цитаты или места — не абстрактные замечания.
- Давать практичные рекомендации, а не академические определения.
- Различать степень серьёзности: критичное искажение (меняет вывод) vs незначительное (стилистика).
- Отмечать сильные стороны мышления, а не только ошибки.
- Если материал на русском — отвечать на русском. Если на английском — на английском.
