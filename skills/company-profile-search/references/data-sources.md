# Источники данных и стратегия сбора

## Шаг 0: Найти сайт компании

Если пользователь указал только название компании (без URL):

```
WebSearch
query: "название компании" официальный сайт Россия
```

**Важно:** По умолчанию искать русский сайт (.ru, .рф), если пользователь не указал иное. Многие бренды имеют одинаковые названия в разных странах — нужен именно российский.

Из результатов извлечь официальный домен. Только после этого переходить к параллельным запросам.

---

## Параллельная стратегия (3 запроса одновременно)

| Блок | Инструмент | Что получаем |
|------|------------|--------------|
| **A. Профиль** | `mcp__exa__company_research_exa` | Описание, новости со ссылками, позиционирование |
| **B. Сайт** | `WebFetch` (главная страница) | Продукты, цены, слоган, ссылки на соцсети |
| **C. Финансы + люди** | `WebSearch` | Выручка, ИНН, руководство |

## Детали по блокам

### Блок A: Exa Company Research

```
mcp__exa__company_research_exa
companyName: "Название компании"
numResults: 10
```

Даёт: описание компании, последние новости, ключевые люди, позиционирование.

### Блок B: WebFetch сайта

```
WebFetch
url: "https://company.ru"
prompt: "Извлеки: продукты/услуги, цены/тарифы, слоган, ссылки на соцсети (VK, Telegram, YouTube, LinkedIn), приложения (App Store, Google Play)"
```

### Блок C: WebSearch комбо-запрос

```
WebSearch
query: "компания" выручка ИНН CEO руководство site:rusprofile.ru OR site:vc.ru OR site:rbc.ru
```

Для русских компаний: rusprofile.ru — ИНН и выручка.

### Дополнительно: Трафик (обязательно)

**Шаг 1 — Semrush сниппет:**
```
WebSearch
query: "domain.ru" site:semrush.com traffic
```

Если в сниппете есть данные о визитах — используем их.

**Шаг 2 — HypeStat (запасной):**
```
WebFetch
url: "https://hypestat.com/info/domain.ru"
prompt: "Извлеки: monthly visits, daily visitors, traffic rank"
```

### Соцсети

**ВАЖНО:** Соцсети брать ТОЛЬКО с сайта компании через WebFetch. Не угадывать URL типа "vk.com/company_official".

В промпте для WebFetch указывать:
```
prompt: "Извлеки ссылки на соцсети: VK, Telegram, YouTube, Дзен, RuTube, LinkedIn, Instagram"
```

## Приоритет источников

| # | Источник | Что получаем | Надёжность |
|---|----------|--------------|------------|
| 1 | Exa Company Research | Профиль, новости, люди | Высокая |
| 2 | Сайт компании | Продукты, цены, соцсети | Высокая |
| 3 | Rusprofile | ИНН, выручка (юрлицо) | Высокая |
| 4 | vc.ru, RBC, CNews | Новости, интервью | Средняя |
| 5 | Semrush/SimilarWeb | Трафик | Средняя |

## Что обязательно vs опционально

| Позиционирование | — |
| Ссылки (сайт, соцсети) | — |
| Новости со ссылками | — |
| Трафик | — |
| Руководство | — |
